February 26, 2009

Date and .do file for “Are Women More Credit Constrained,” de Mel, McKenzie and
Woodruff.

Place all of the data files in a directory. The single .do file produces all of the results in
the paper which come from the Sri Lankan survey data.

The raw data are available at: http://cpe.ucsd.edu/research/slms.htm

Data files included in archive:
gender_AEJApp.do : .do script which produced the results.
SLMSMaster : data file, main data
Famhours_baseline: data file, data on hours worked by family members, baseline survey
Int_pres: data file, data on who was present at the interview
propfem: data file, data on the proportion of owners who are female by detailed industry
Treatment1_2: data file, data detailing categories of expenditures of in-kind treatments
Treatment_reported: data file, data on amount actually spent for in-kind treatments
Tsunami_track9all: data file, data for wave 9 f the panel survey (brings in certain
variables not included in the master data set.)
Tsunami_track11f: data file, wave 11 fixed variables (brings in certain variables not
included in the master data set.)
